# 功能范围

## 定位

在自己的电脑运行 Claude Code agent，通过自托管 relay，让本人从手机或其他浏览器
继续会话。项目是个人工具，不提供多用户之间的权限隔离。

## 当前能力

- 流式对话、工具调用与子代理过程展示。
- 查看、继续、重命名、归档和删除 Claude 会话；右键菜单与多选批量归档；复制会话工作目录。
- 默认隐藏临时会话（临时目录下的、`claude -p` 等非交互运行的），可在列表筛选里显示。
- 多机器在线状态与会话列表；每个浏览器独立配对。
- 权限确认、交互式问题、计划展示与运行状态。
- 回退到某条用户消息之前（对应 Claude Code `/rewind`）：还原代码、回退对话或两者都做，先预览再确认。
- 工作目录选择、命令面板、Claude 版本检查与更新入口。
- 端到端加密消息、短码人工校验、断线重连和离线补发。
- 可选 Bark 通知（事件类型和机器标识）。

## 运行前提

使用自己的模型提供方账户与合法授权；费用和模型访问能力由提供方决定。
Agent 必须获得执行 Claude 的 OS 权限，用户应审查每次授权并限制所用账户。
浏览器与 agent 需同时满足 [SECURITY.md](../SECURITY.md) 的信任边界。

## 非目标

- 多租户 SaaS 或多人共享 relay。
- 通用远程终端与完整远程文件编辑器。
- 非 Claude CLI 的统一代理层。
- 完善的设备撤销控制台、自动灾难恢复或高可用集群。
- 对 Windows 的完整支持承诺。

协议/UI 行为详见 [PROTOCOL-REQUIREMENTS.md](PROTOCOL-REQUIREMENTS.md)。
